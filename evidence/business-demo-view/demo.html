模型解释（原文，可能不准确，以测试为准）
The original code did not correctly handle skipped tests and did not raise an error for unknown statuses. The updated code now correctly excludes skipped tests from the pass rate denominator and raises a ValueError for unknown statuses. It also ensures that the pass_rate is calculated correctly even if there are no executed tests.
